The control

Three marks replace the Capture button and its caret. Each one says why the capture is being taken and opens the panel. Above, 👎 is lit. Clicking 🤔 would change the mark and leave the panel and anything typed in it alone; clicking 👎 again closes the panel, as Escape and a click outside do.

Every capture now carries a mark, because there is no other way in. Saving costs a second click, and buys a field nobody has to read prose to recover.

Unlit, and each one lit

Unlit sits at 0.55 opacity. Lit takes the raised chip the view toggle already draws, and a border that tells the three apart — the success green for 👍, the control border for 🤔, the rust the inspector already spends on text/html for 👎. No new colour enters the sheet.

A green-amber-red bar was the other candidate. It reads as a satisfaction scale, and 🤔 is not a lukewarm verdict — it marks a question, which is a different axis. Amber would tell the reader "somewhat unhappy". Three chips carry three meanings; a graded bar carries one.

The panel, with the note first

The note is what the tester came to write, so the panel asks for it before it asks which panes to keep. One box replaces Expected, Observed and Cause, and its placeholder changes with the mark — the one below is what 👎 gets.

An empty clipboard still saves

Save stays live even when no pane is available. The console rides in whatever else is ticked, and a run that produced nothing is often the one worth reading. The old refusal — the button flashing "Nothing yet" — goes with the button.
