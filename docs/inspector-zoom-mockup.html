A zoom control for the preview panes

The panes are capped and scroll past the cap, so a spreadsheet copy shows its first few rows and hides its shape. Zooming out puts the whole payload back in the frame — on both sides of the comparison at once.

It works — try it. It opens at Fit, the way the inspector does, with the menu showing. Pick a level and watch the four panes, not the chrome. Ctrl/⌘ + − 0 work too.

The panes move, the page does not

Headers, byte counts, savings figures and the replace buttons hold their size at every level. They are how the grid is read and operated; only the payload scales.

One number, both columns

Fitting each pane separately would pack the cards tighter, but a row exists to be compared, and two panes at different scales cannot be. Fit takes the largest scale at which every pane clears its cap, and stops at 50%.

Left of Rendered / Source

One control says what the panes show, the other how big. A hairline separates them so the pair does not read as one four-button cluster.

Height first, zoom second

Both buy the same thing; only one costs legibility. So the shipped version hands the panes whatever height the window is not using — split between the two rows by what each is holding — and Fit is left to deal with the remainder. On a tall window it has nothing to do. This page keeps the old fixed heights, so the zoom does all the work here.

Built on an inner layer

zoom scales an element's own lengths too, so it goes on a layer inside each pane. Put it on .card-render and the 200px cap scales with it — the cards would grow, instead of showing more.

Settled

  • Every inspect opens at Fit. Nothing is remembered between reads: a copy is worth seeing whole before it is worth reading, and the size that takes belongs to the copy, not to the last one.
  • Fit stops at 50%. Past that the payload is no longer readable, so a copy too long to fit goes back to doing what it always did — showing what it can, and scrolling for the rest.
  • Width is left to the wrap toggle. Fit measures height only. Long lines are a per-pane question, and the toggle in each card head already answers it.
  • A pane grows before it shrinks its payload. The 200px and 300px caps became a floor rather than a height: the panes take whatever the window is not using first, and Fit only handles what is still over. Left as it is on this page, which keeps the fixed caps so the zoom has something to do.
